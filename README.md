# Книжный клуб — Telegram Mini App

Каталог книг клуба, отзывы с оценкой 1–5 и даты встреч. Открывается прямо из группы в Telegram, без регистрации: пользователя отдаёт сам Telegram.

- **Бэкенд:** Go 1.24, только стандартная библиотека. Один бинарник, фронт вшит внутрь через `embed`.
- **Фронт:** HTML + JS + CSS без сборки. Крупный шрифт и кнопки, цвета из темы Telegram.
- **Данные:** один JSON-файл (`data/bookclub.json`).

## Что умеет

| | Участник | Администратор (`ADMIN_IDS`) |
|---|---|---|
| Смотреть книги, отзывы, встречи | ✓ | ✓ |
| Добавить книгу (название, автор, ссылка, пара слов) | ✓ | ✓ |
| Удалить книгу | только свою | любую |
| Оставить или изменить свой отзыв (одна книга — один отзыв) | ✓ | ✓ |
| Удалить отзыв | только свой | любой |
| Назначить, изменить, удалить встречу | — | ✓ |

## Запуск локально

```bash
DEV_MODE=1 ADMIN_IDS=1 go run ./cmd/bookclub
```

Откройте http://localhost:8080/?dev=1:Анна — вы администратор Анна. Второй участник: http://localhost:8080/?dev=2:Маша (в другой вкладке).

`DEV_MODE=1` разрешает входить без Telegram под любым именем. **На сервере его не включать.**

```bash
go test -race ./...
```

## Структура

```
cmd/bookclub/        main: конфиг из env, сборка зависимостей, graceful shutdown
internal/auth/       проверка подписи initData (HMAC-SHA256 от токена бота)
internal/tg/         проверка, что пользователь состоит в группе клуба (getChatMember + кэш)
internal/store/      хранилище: всё в памяти, каждая запись атомарно переписывает JSON-файл
internal/api/        HTTP: роуты, права, валидация, DTO
web/static/          фронт: index.html, app.js, style.css
```

## Настройка в Telegram

Нужен адрес с **HTTPS** — Telegram открывает Mini App только по https.

1. **Бот.** В @BotFather: `/newbot` → получите токен (`BOT_TOKEN`).
2. **Mini App.** Там же `/newapp` → выберите бота, укажите URL сервера и короткое имя, например `club`. Ссылка на приложение: `https://t.me/<имя_бота>/club`.
3. **Ссылка в группе.** Отправьте эту ссылку в группу клуба и закрепите. По нажатию приложение откроется внутри Telegram.
4. **Только для участников (рекомендую).** Добавьте бота в группу, затем узнайте ID группы:
   - напишите в группе `/start@<имя_бота>`;
   - откройте `https://api.telegram.org/bot<TOKEN>/getUpdates` и найдите `"chat":{"id":-100…}`.

   Этот ID укажите в `CLUB_CHAT_ID`. Тогда войти смогут только участники группы, даже если ссылка уйдёт наружу.
5. **Администраторы.** Пусть будущий администратор откроет приложение: внизу экрана видно «ID 123456». Этот же ID есть в логе сервера (`user seen`). Впишите его в `ADMIN_IDS` и перезапустите сервер.

## Переменные окружения

| Переменная | По умолчанию | |
|---|---|---|
| `BOT_TOKEN` | — | Токен бота. Обязателен, если не `DEV_MODE=1` |
| `CLUB_CHAT_ID` | пусто | ID группы клуба. Пусто — проверки членства нет |
| `ADMIN_IDS` | пусто | Telegram ID администраторов через запятую |
| `ADDR` | `:8080` | Адрес HTTP-сервера |
| `DATA_FILE` | `data/bookclub.json` | Файл с данными |
| `INITDATA_MAX_AGE` | `24h` | Сколько действует вход после открытия приложения |
| `DEV_MODE` | — | `1` = вход без Telegram, только для разработки |

## Деплой (когда выберем хостинг)

Сервер должен открываться у участниц **без VPN**, поэтому подойдёт российский VPS. С самого сервера должен быть доступен `api.telegram.org` (для `CLUB_CHAT_ID`).

**Вариант без Docker.** Соберите бинарник под Linux:

```bash
GOOS=linux GOARCH=amd64 go build -o bookclub ./cmd/bookclub
```

Запустите его через systemd, а HTTPS отдайте Caddy — он сам получает сертификат. Весь `Caddyfile`:

```
club.example.ru {
    reverse_proxy 127.0.0.1:8080
}
```

**Вариант с Docker:**

```bash
docker build -t bookclub .
docker run -d --restart unless-stopped -p 127.0.0.1:8080:8080 \
  -v bookclub-data:/data \
  -e BOT_TOKEN=... -e CLUB_CHAT_ID=... -e ADMIN_IDS=... \
  bookclub
```

**Бэкап** — копия `bookclub.json` раз в сутки (cron + `cp`). Файл пишется атомарно, поэтому копировать его можно в любой момент.

## Решения, на которые стоит посмотреть на ревью

- **Ноль зависимостей.** Роутинг на `net/http` из Go 1.22 (`GET /api/books/{id}`), логи на `log/slog`.
- **JSON вместо БД.** Клуб — это сотни записей в год. `mutate()` меняет копию данных, пишет её на диск (temp + fsync + rename) и только потом подменяет состояние в памяти. Упала запись — не меняется ни файл, ни память. Хранилище спрятано за интерфейсом `api.Store`: SQLite подключается новой реализацией без правок в хендлерах.
- **Аутентификация.** Фронт шлёт `Authorization: tma <initData>`, сервер проверяет HMAC и срок давности. ID других участников наружу не отдаются, только имена.
- **Членство в группе.** Ответ `getChatMember` кэшируется: «да» на 10 минут, «нет» на 1 минуту. Если Telegram недоступен, используется последний известный ответ. Ошибки чистятся от URL, потому что в нём токен бота.
- **XSS.** Фронт кладёт пользовательские данные в DOM только через `textContent` (функция `h()`), сервер принимает ссылки только `http(s)`.
- **Старшее поколение.** Шрифт 18px, кнопки от 52px, подписи словами, а не иконками. Подтверждения через нативный диалог Telegram, системная кнопка «Назад». Случайное закрытие свайпом отключено.
